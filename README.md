# Alvarocean demo

Demo estática de la home de Alvarocean para GitHub Pages.

- Solo contiene la home y los recursos necesarios.
- Incluye `noindex, nofollow` para no competir con la web oficial.
- El formulario es únicamente visual en esta demo; no envía datos.
- Las tarjetas de Work abren sus vídeos de YouTube en un popup sin salir de la home.
- No contiene PHP, credenciales ni configuración de WordPress.
